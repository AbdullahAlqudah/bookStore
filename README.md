# Bookstore & Reading Club

A simple interactive bookstore and reading club project built using HTML, CSS, and JavaScript.

## Features

- User registration
- Membership selection
- Book genre selection
- Book reservation
- DOM manipulation
- Event listeners
- Form validation
- Arrays and functions
- Shopping list
- Test scores application
- Interactive text editor

## DOM & Events Exercises

The project includes:

- Basic Registration Form
- Paragraph DOM Exercises
- Shopping List
- Test Scores
- Interactive Text Editor
